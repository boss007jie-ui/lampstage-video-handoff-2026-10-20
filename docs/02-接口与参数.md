源码权威入口：`source/apps/web/lib/video/backends/{contracts,runninghub-protocol,runninghub}.ts`。样例见 `contracts/protocol-examples.json`；除明确的源码常量外，ID/素材/返回值为脱敏结构或协议合成，**没有真实接口捕获记录**。

以下通过 agent-reach 的 Jina Reader 读取 RunningHub 官方页面；页面摘要和内容校验值见 `docs/official-doc-check.json`。只确认通用接口，未验证任何账户、私有App、节点语义或收费。

|---|---|---|
| 文件上传 | [文件上传](https://www.runninghub.cn/runninghub-api-doc-cn/api-425749007)：`POST /openapi/v2/media/upload/binary`，Bearer，multipart字段`file`。成功`code:0`，`data.fileName`、`download_url`、`type`、`size`；示例size为字符串 | W1未实现上传 |
| AI应用提交 | [提交](https://www.runninghub.cn/runninghub-api-doc-cn/api-425749010)：`POST /task/openapi/ai-app/run`；Bearer及JSON apiKey/webappId/nodeInfoList；每项nodeId/fieldName/fieldValue；回执data.taskId | W1已构造/解析，默认业务mode未启用 |
| 查询原任务 | [outputs](https://www.runninghub.cn/runninghub-api-doc-cn/api-425749004)：`POST /task/openapi/outputs`，JSON apiKey/taskId，成功data[]内fileUrl/fileType | W1固定`legacy-outputs-v1`，status和results都调用它；这是只读POST，不是生成POST |

上传返回的`fileName`是服务器相对路径，供相应ComfyUI加载节点使用；`download_url`用于标准模型API，不能任意互换或把fileName拼成外链。官方上传页说明该**上传链接**有效期一天；这不是生成结果fileUrl的TTL。具体本App用哪种输入、哪一个nodeId/fieldName、是否支持URL节点仍未知。二进制上传接口本身不接收URL输入；有云存储外链也必须使用实际支持它的节点。[上传说明](https://www.runninghub.cn/runninghub-api-doc-cn/api-425749007)

## 哪些参数是实际真值

`workflows/provider-configuration-status.json`对每个未知项保留null。源码默认只读工作流ID为`2102537586127491074`，它不是已验证AppID，也不证明接收方有权限。旧Hypit能力名`@hypit/minimax-h3@1#minimax-h3`和provider名只表示本地契约；无法证明模型权重、custom node或供应商配置版本。

| 参数 | 类型/必填/默认/范围 | 已核实程度 |
|---|---|---|
| accountId/mappingVersion | W1非空安全标识，最多80字符，必填，无真实默认 | 结构约束已实现，实际值缺失 |
| webappId/nodeId/taskId | 字符串数字ID，最多64位；禁止JS数值精度丢失 | 结构约束已实现，真实App/节点缺失；taskId只从原回执取 |
| bindings.inputKey / fieldName | 安全标识，最多80字符；无重复key或重复nodeId:fieldName | 结构约束已实现，真实绑定缺失 |
| values[inputKey] | 每项string、≤1,000,000字符；键集合恰好等于bindings；无业务默认 | 真实参数类型、必填、默认、取值范围待从App配置取得 |
| timeoutMs | 1–120000整数，默认30000 | 本地单请求时限，不是生成最长时限 |
| expiresAt | null | 生成结果TTL未核实，不能编造 |

真实图片/视频/音频节点行目前**无法列出**；官方文档中的示例nodeId与本包fixtures中的1/2/3/4均不是Lampstage真实映射。不能把业务字段duration=4/5/6/8直接当成某节点参数范围。

旧参考帧阶段使用OpenLux原生HTTP模型API，无AppID、工作流图或custom node可导出；源码中的v1beta端点、别名、两图inlineData顺序和生成参数见`contracts/protocol-examples.json.referenceImageStage`及`workflows/provider-configuration-status.json.referenceImageStage`。默认不加imageSize；通用builder只接受显式2K选项，视频入口本身未传。源码可解析Gemini候选中的inlineData或fileData，再作真实图片校验/裁切；没有持久taskId查询/取消接口或供应商幂等键。付费图片POST超时后不能自动重试，需由宿主保留未知花费并核对；这项真实模型端点当前可用性、实际模型build、权限/费率本次也未验证，不能用视频W1的taskId查询恢复它。

## 异常与重试

| 情况 | 归一化结果 | 上层动作 |
|---|---|---|
| 本地未配置、非法输入、gate明确拒绝 | definite_not_submitted | 不自动重投；先核对原记录/审批与预算，确认为新attempt后再处理 |
| HTTP成功且code0+安全字符串taskId | accepted(taskId) | 立即CAS持久化；仅此taskId查询，尚非生成成功 |
| 付费POST超时/断连/非2xx/畸形响应 | submission_unknown | 保留intent/占用，不补发；有taskId查原任务，无ID进入人工核对 |
| 拒绝码伴taskId字段（含null/数值/非法） | submission_conflict/unknown | 不能认定未创建。明确拒绝仅限源码白名单且taskId字段完全缺失 |
| 查询804/813 | running/queued | 有界退避查询同一taskId |
| 查询805 | failed | 可信供应商终态失败；不能自动生成替代任务或宣称RH退款 |
| 查询404/807/423/不认识响应 | read_error | 不推断未提交；不重新生成 |
| 查询408/429/5xx/网络异常 | retryable read_error | 仅重试原taskId查询，不适用于付费submit |
| 结果URL403或过期 | collector_download_failed，可尝试recover/重查原结果 | 先查本地不可变receipt；再查询原taskId。重查必换链接无保证，仍不得重投 |
| 取消 | unsupported / cancel_unsupported | 宿主可停止新阶段和本地收取；不能声称远端已撤销或费用已返还 |

供应商没有在本代码中接入幂等键，`intentId`不是RunningHub幂等参数。持久gate最多约束本方一次发送权，不能消除“发送后未保存回执”窗口；未知时不重投才是边界。签名URL仅供私有收取，不写公开事件；公开投影只保留状态、安全code和outputCount。

## 字段与费用

`backendId`绑定供应商/逻辑账户/App/映射版本/查询协议/配置摘要；`configurationDigest`不含密钥。`intentId/inputDigest/fence`是本方授权与重入记录；`providerTaskId`是远端查询身份；旧Hypit `buildId`是本地运行时身份，不能当RH taskId。上传引用需保存fileName/download_url及用途、所属账户/素材hash和时效，不能作为永久产物。收取后保存本地key、SHA256、sizeBytes、duration、width、height和identityDigest，再让下一阶段读取不可变产物。

本代码`billing=false`，未采集真实RH费用。outputs官方示例出现consumeCoins等字段，代码刻意不当账单透传；币种换算、计费规则/退款、会员/账户并发、真实模型费用均未核实。平台credits、本地maxCoins和W2 video_second三者不是供应商账单；maxCoins没有传给供应商作硬封顶。正式计费需账户侧只读账单/明确供应商说明，本包没有编造价格。

私有App运行需应用所有者向接收方授权，或由权利人提供可合法导入的图与所需模型/custom nodes；接收方在自有账户发布副本后，应重新获取AppID/调用映射、核对权限并冻结新配置摘要。只有App ID、旧运行结果或只读workflow ID都不足以恢复运行。不要把原attempt换成新App重投。
